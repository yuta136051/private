# 電子書籍 → 検索可能PDF化

## 最初にルートを判定する（必ずやる）

対象ページで本文が**テキストとして取れるか**を先に確認する。

```js
const c = document.querySelector('<本文コンテナのセレクタ>');
JSON.stringify({ textLen: c.innerText.length, imgs: c.querySelectorAll('img').length })
```

| 結果 | ルート |
|---|---|
| 本文が読めるテキストとして取れる | **→ [`html_route/README.md`](html_route/README.md)**（本文を直接抽出。誤字ゼロ・速い・図表だけOCR） |
| 本文が画像/canvasでテキストが取れない | → 以下のスクショルート（このファイル） |

スクショ+OCRは**テキストが取れないときの手段**であって、常用する手順ではない。
テキストが取れるのにスクショを撮ると、遅いうえに本文にOCR誤字が入る（もったいない）。

# （画像ビューワー用）スクショ → OCR付きPDF化

スクリプトは**このSKILL.mdと同じディレクトリ**（`.claude/skills/ebook-viewer-to-pdf/`）に置いてある。**書き直さずそのまま使う。**

| ファイル | 役割 |
|---|---|
| `lib.ps1` | DPI対応・強制前面化・最前面固定・クリック・撮影の共通処理 |
| `setup.ps1` | ページ移動・プレゼンモード投入・確認用スクショ・後片付け |
| `capture.ps1` | 全ページ撮影（全画面が外れたら自動復帰） |
| `trim.py` | ページ境界を1枚ずつ検出して正確に切り出し |
| `make_pdf.py` | 画像のみPDFに結合 |
| `vcolumns.py` | 縦書きの列・文字位置の検出 |
| `make_ocr_pdf.py` | OCR付き（検索可能）PDF生成 |
| `verify.py` | ページ数・抽出テキストの検証 |

依存: `pip install img2pdf Pillow numpy pypdf manga-ocr easyocr reportlab`

## 大原則

- **Claudeが1ページずつツールを呼ぶのは絶対にやらない。** PowerShell 1本がループ全体を完結させる。
- **Chrome拡張(claude-in-chrome)は使わない。** 操作が遅いうえ、ビューワーによっては別タブで開いた瞬間に元のセッションが切られる。OSレベルのキー送信で操作する。
- **タブは1つだけ。** 同じ本を2つのタブで開かない。

## 手順

### 1. 下見
- 対象タブを表示した状態でスクショを撮り、**総ページ数**とツールバーの**ページ番号欄の座標**を実測する。
  ```
  powershell -File setup.ps1 -Shot
  ```
- 画面の実解像度を確認（`Get-CimInstance Win32_VideoController`）。撮影スクリプト内の値と一致しなければDPI対応が効いていない＝低画質になる。

### 2. プレゼンテーションモードに入る（ここが品質と手間を決める）
PDF.js系ビューワーなら **Ctrl+Alt+P** で1画面=1ページの全画面表示になる。黒地に紙面が中央表示され、ツールバーも消えるので、ズーム調整もクロップ実測も不要になる。
```
powershell -File setup.ps1 -GoToPage 1 -Present -Shot
```
- ページ送りは **→ キーで正確に1ページ**。`Home` で先頭に戻る。
- Chromeの「Escで全画面終了」通知が数秒出るので、撮影開始前に4秒待つ（capture.ps1 が待つ）。
- プレゼンモードが無いビューワーの場合のみ、F11＋ズーム「ページ全体を表示」で代用し、クロップ範囲を実測する。

### 3. 試し撮り
```
powershell -File capture.ps1 -StartIndex 1 -EndIndex 6 -OutDir <tmp>\test
```
必ず目視してから本番へ進む。

### 4. 本撮影（`run_in_background: true` で1回だけ）
```
powershell -File capture.ps1 -Pages <総ページ数> -OutDir <tmp>\capture
```
- 実行中はユーザーにマウス・キーボードを触らないよう伝える（約1.5秒/ページ）。
- 途中で全画面が外れても自動復帰する。復帰できなければ中断し、`-StartIndex N` で再開する。
- 終了時のログの「直前と同一の画面」警告は、白紙ページなら正常。

### 5. トリミング → 画像PDF
```
python trim.py --src <tmp>\capture --out <tmp>\trimmed
python make_pdf.py --src <tmp>\trimmed --out "<デスクトップ>\<書名>.pdf"
```
`OUTLIER` が出た画像は必ず目視する。先頭・中間・終盤も目視する。

### 6. 後片付け（撮影が終わったらすぐ）
```
powershell -File setup.ps1 -Keys "{ESC}" -Release
```
最前面固定を解除しないとユーザーのChromeが前面に貼り付いたままになる。

### 7. OCR（検索可能PDF）
```
python make_ocr_pdf.py --src <tmp>\trimmed --out test.pdf --start 83 --limit 3   # まず数ページ
python make_ocr_pdf.py --src <tmp>\trimmed --out ocr_out.pdf                     # 本番(バックグラウンド)
python verify.py --pdf ocr_out.pdf --expect <総ページ数> --words 漢方 コロナ
```
- 日本語ファイル名はシェル経由で渡さず、ASCII名で出力してから PowerShell の `Copy-Item` でリネームする。
- 所要時間の目安: 2コアCPUで **約19秒/ページ**（168ページで約53分）。着手前にユーザーへ伝える。
- 完了時に必ず伝える: 見た目は元画像のまま／裏にテキスト層を足しただけ／誤字は残るので検索用途向けで文章のコピーには向かない。

## 落とし穴（すべて実際にハマった）

**ビューワーの同時起動制限**: 同じ本を2つ目のタブで開くと、元のタブが「別のブラウザで開かれたためビューアを終了します」となり、**新しいタブ側も真っ白で描画されない**。真っ白＝デバッガ検知だと誤診しやすいが原因はこれ。リロードすれば復活する。

**Claude Codeのウィンドウが常に最前面**: Chromeをフォーカスしても画面キャプチャにClaude側が写り込む。`Set-ChromeTopmost` でChromeを最前面固定してから撮る（`PrintWindow` はGPU描画のページ本体が写らないので使えない）。**終わったら必ず解除する。**

**SetForegroundWindowが効かない**: バックグラウンドプロセスからは無視される。`AttachThreadInput` で紐付けてから呼ぶ（lib.ps1 の `ForceForeground`）。

**全画面が途中で外れる**: 放置すると残り全ページが同じ画面の連続になる。`capture.ps1` は毎フレーム左下すみの明るさで判定して自動復帰する。**この検出が無いと100ページ無駄になる。**

**縦書き日本語はEasyOCRで読めない**: 出力が無意味な1文字の羅列になる。縦書きは `manga-ocr` を使い、**列を検出 → 文字の切れ目で14文字ずつに分割** して渡す。列を丸ごと渡すと（224x224にリサイズされるため）まったく読めない。

**チャンク文字数は14が最適**（実測）:
- 10文字より14文字の方が **21%速く、しかも精度が高い**（境界での文字重複が減る）
- 18文字から劣化しはじめ、22文字以上で崩壊する

**やっても速くならなかったこと**（再検証しなくてよい）:
- int8動的量子化: 約10%速いが数字を誤認する（70%→20%）
- マルチプロセス: 2コアCPUでは1プロセス4スレッドより遅い
- バッチサイズ24: 12と変わらない

**Tesseract + ocrmypdf**: Windows版は管理者権限を要求し、自動化シェルからは `winget` でも `/S` 付き直接実行でも失敗する。管理者権限を対話的に得られないなら早々に見切る。

**.ps1に日本語コメントを書くならUTF-8 BOM必須**: Windows PowerShell 5.1 はBOM無しUTF-8をANSIとして読むため、日本語コメントが化けて構文エラーになる（`Unexpected token '}'` など無関係な場所で落ちるので原因に気づきにくい）。スクリプトを編集したら必ず:
```powershell
$c = Get-Content -Raw -Encoding UTF8 $p
[System.IO.File]::WriteAllText($p, $c, (New-Object System.Text.UTF8Encoding $true))
```

**OCR結果の確認**: 抽出テキストは必ずUTF-8ファイルに書き出してからReadで読む。コンソール直接だと化けて、正しいのに壊れていると誤判断する（`verify.py` がこれをやる）。
